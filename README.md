# ForTrainingNG skin (4training)

This is a skin with a new design study for www.4training.net (unfinished)

It is based on the example skin
https://www.mediawiki.org/wiki/Skin:Example

using the new MediaWiki skinning approach with Mustache.

## Installation

To try it out, first clone this repository.
Then use the [4training docker container](https://github.com/4training/docker)
to get a local version of the 4training.net website with a simple `docker compose up`.
See its [Readme](https://github.com/4training/docker?tab=readme-ov-file#using-this-for-development) and add a line in the `volumes:` section to override the default skin and load this skin instead.
